# RunLog screenshots

Drop image files in this folder and they appear on the RunLog case study. No code change is needed.
(Delete this README after the images are in, or leave it; it is not served as an image.)

| File name | Where it shows |
| --- | --- |
| `cover.png` | Big image under the title, and the small thumbnail in the Projects lists |
| `og.png` | Link preview when the case study is shared (1200 x 630 px). Falls back to `cover.png` |
| `1.png`, `2.png`, `3.png`... | Screenshot grid below the text, in file-name order |

`.png`, `.jpg` and `.webp` all work. Keep each file under about 400 KB.
Do not use screenshots that show a home address or a private run start/end.
